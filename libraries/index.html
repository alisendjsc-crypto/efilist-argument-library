The flagship argues that coming into existence is a harm. The four wings are rebut-only optionality defenses: each answers the objections to a contested liberty without urging anyone to exercise it. Veganism is not a wing but a flagship-adjacent module: it argues harm on the flagship’s own register rather than defending a choice. “Refusal Libraries” is a venue name, not a category claim — every card below carries its own register. The Adversarial Map

A hostile pass over all eighty-two flagship nodes: for each one, the strongest continuation a maximally competent opponent would deploy against the text as shipped, sorted into four dispositions — already answered, needs a stronger text, is actually a new objection, or names bedrock and stops.
