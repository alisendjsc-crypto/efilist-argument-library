## Why no further node (consolidation survey)

G1 individuates a node by **distinct ground**, not by rebuttal-move — every node routes through the spine's permission-to-decline; that shared engine is not subsumption.

- **AI-as-Separation** → FAILS. Substrate-templated; its only non-substrate rescue is artifactuality, which bifurcates (below).
- **Bio-Chauvinism** → FAILS both ways. "life-as-such" → substrate; "life-over-non-life / special pleading" (tu-quoque) → spine.
- **Artifactuality / made-vs-born** (the close call) → FAILS by **bifurcation**. The teleological-void premise ("made-for-purpose voids standing") has no stable distinct cashing-out: the **end-ownership** reading ("can't self-originate ends") is a *capacity* → **parity**; the **bare-origin** reading ("born just confers standing") is a *primitive* → **brute-kind** template. *Tertium non datur* — origin bears on standing only brutely or via a present feature the made-thing lacks. Secondary defeater: AI-exclusion *over-shoots* the species line (it would enfranchise all born animals), so the wedge can't re-establish human-supremacy. The once-per-arc **axis-fork stays UNSPENT** — correctly. (The "AI is just a tool" intuition is live in 2026; recorded as absorbed-and-routed, not omitted.)
- **contractarian/reciprocity** → parity. **dignity/imago-dei** → parity or brute-kind. **potentiality** → brute-kind/Cohen transmission.
